PathSim: Meta Path-Based Top-K Similarity Search in Heterogeneous Information Networks

Yizhou Sun, Jiawei Han, Xifeng Yan, Philip S. Yu, Tianyi Wu Proceedings of the VLDB Endowment, Vol. 4, No. 11 · 2011
Abstract Similarity search is a primitive operation in database and web search engines. With the advent of large-scale heterogeneous information networks — networks containing multiple types of objects and multiple types of links, such as bibliographic networks and social media networks — existing similarity measures designed for homogeneous networks cannot be directly applied. Two objects connected by many paths in a heterogeneous network may be similar in very different ways depending on the types of links followed. This paper introduces the concept of meta path-based similarity, where a meta path specifies a sequence of relation types at the schema level. Under this framework, the authors define a novel similarity measure called PathSim that finds peer objects sharing not only strong connectivity but also comparable visibility (balance of exposure) in the network. PathSim is more meaningful than random-walk-based measures in many peer-finding scenarios. To support efficient top-k query processing, the paper proposes algorithms that partially materialize short meta paths and concatenate them online, with a co-clustering-based pruning strategy to avoid exhaustive pairwise comparisons.

1. Heterogeneous Information Networks

Most classical graph algorithms and similarity measures assume a homogeneous network: all nodes are the same type of thing (web pages, people, products) and all edges represent the same kind of relationship (links, friendships, purchases). Real-world data networks are rarely like this. A bibliographic database such as DBLP contains four types of objects — papers, authors, venues (conferences and journals), and terms — and multiple types of links connecting them: an author writes a paper, a paper is published-in a venue, a paper uses a term, a paper cites another paper.

Definition — Information Network and Network Schema

An information network is a directed graph $G = (V, E)$ with an object type mapping $\phi: V \to \mathcal{A}$ and a link type mapping $\psi: E \to \mathcal{R}$, where each vertex belongs to exactly one object type and each edge belongs to exactly one relation type. When $|\mathcal{A}| > 1$ or $|\mathcal{R}| > 1$, the network is heterogeneous. The network schema $T_G = (\mathcal{A}, \mathcal{R})$ is a directed graph over object types with edges labeled by relation types.

The challenge that heterogeneity introduces for similarity search is semantic ambiguity. Two authors in DBLP can be connected by many different paths. The path author — paper — author (abbreviated APA) counts co-authorship. The path author — paper — venue — paper — author (APVPA) connects authors who publish in the same venues. The path author — paper — term — paper — author (APTPA) connects authors whose papers use the same vocabulary. Each path tells a different story about what "similar" means. Blindly mixing all paths — as a random walk on the full heterogeneous graph would do — conflates these distinct notions and gives results that are hard to interpret.

2. What Is a Meta Path?

A meta path is the paper's key organizing concept. It lifts the idea of a path from the object level (specific nodes) to the schema level (types of nodes and edges).

Definition — Meta Path

A meta path $\mathcal{P}$ is a path defined on the network schema $T_G = (\mathcal{A}, \mathcal{R})$ of the form $$A_1 \xrightarrow{R_1} A_2 \xrightarrow{R_2} \cdots \xrightarrow{R_l} A_{l+1}$$ which defines a composite relation $R = R_1 \circ R_2 \circ \cdots \circ R_l$ between types $A_1$ and $A_{l+1}$. A path instance $p$ is an actual sequence of nodes in $G$ that follows the meta path schema.

A meta path is symmetric if the relation it defines is symmetric, i.e., if $A_1$ equals $A_{l+1}$ and the sequence of relation types reads the same forward and backward. The meta path $APA$ (author–paper–author) is symmetric. PathSim is defined only for symmetric meta paths, because similarity between peers of the same type should be symmetric.

Example — Meta paths in DBLP

In the DBLP bibliographic network with authors (A), papers (P), venues (C), and terms (T):

  • APA: two authors are similar if they have co-authored papers. This is a length-2 symmetric meta path.
  • APCPA: two authors are similar if they have published in the same venues (conferences/journals). They need not have co-authored anything.
  • APTPA: two authors are similar if their papers use similar vocabulary.
  • APAPA: two authors are similar if they have co-authors in common.
Each meta path defines a different similarity semantics. A user selects the meta path that matches their notion of "similar" for a given application.

3. Why Existing Similarity Measures Fail

Given a meta path, the naive way to measure similarity between two objects $x_i$ and $x_j$ is to count the number of path instances between them: $s(x_i, x_j) = |\{p : p \in \mathcal{P}\}|$. This is the path count. It has an obvious flaw: prolific, high-visibility authors will have large path counts with almost everyone. An author who has published 500 papers will have co-authors connecting to thousands of others. Path count is dominated by degree, not by genuine semantic similarity.

Random walk and pairwise random walk (PRW) measures normalize differently but still tend to favor either highly visible objects (random walk) or concentrated objects with a small number of very strong connections (pairwise random walk). SimRank, which measures structural context similarity, is biased toward concentrated objects. The common failure mode is this: when you ask "who are the authors most similar to Mike?", you want to find Mike's peers — researchers working on the same topics with similar publication records. You do not want to find the most famous people in the field, nor the most isolated niche researchers. Existing measures struggle to distinguish peer similarity from prominence.

The peer similarity intuition

Think about what makes two people genuine peers. They should be connected to each other through the network (connectivity), but they should also have comparable exposure in the network. Two prolific professors who rarely co-author are still peers if they work in the same area. A postdoc and a famous professor are probably not peers even if they co-authored one paper, because their overall visibility in the network is very different. PathSim captures this by requiring both strong connectivity and similar visibility.

4. PathSim: The Similarity Formula

PathSim confines attention to symmetric meta paths — round-trip paths of the form $\mathcal{P} = (\mathcal{P}_l \mathcal{P}_l^{-1})$, where $\mathcal{P}_l^{-1}$ is the reverse of $\mathcal{P}_l$. On such a path, the similarity between two objects of the same type is:

$$s(x_i, x_j) = \frac{2 \times |\{p_{x_i \to x_j} : p_{x_i \to x_j} \in \mathcal{P}\}|}{|\{p_{x_i \to x_i} : p_{x_i \to x_i} \in \mathcal{P}\}| + |\{p_{x_j \to x_j} : p_{x_j \to x_j} \in \mathcal{P}\}|}$$

Let's read this formula slowly. The numerator counts the path instances from $x_i$ to $x_j$ following the meta path $\mathcal{P}$, multiplied by 2. The denominator adds the number of paths from $x_i$ back to itself (its self-connectivity, measuring its own visibility) to the number of paths from $x_j$ back to itself (its own visibility).

This is structurally identical to Dice's coefficient from ecology — a measure of overlap between two sets that normalizes by the sum of the set sizes. Here, the "sets" are the path neighborhoods of the two objects. The self-loop count $M_{ii}$ for object $x_i$ is the number of ways to walk from $x_i$ through the meta path and return to $x_i$. For APA (author–paper–author), this is simply the number of papers $x_i$ has authored (each paper contributes one round trip). It directly measures the author's output — their "visibility" on this meta path.

Properties of PathSim (Theorem 1 in the paper)

PathSim satisfies three important properties:

  1. Symmetric: $s(x_i, x_j) = s(x_j, x_i)$.
  2. Self-maximum: $s(x_i, x_j) \in [0, 1]$ and $s(x_i, x_i) = 1$.
  3. Balance of Visibility: $s(x_i, x_j) \leq \dfrac{2}{\sqrt{M_{ii}/M_{jj}} + \sqrt{M_{jj}/M_{ii}}}$. This upper bound is 1 only when $M_{ii} = M_{jj}$, i.e., when both objects have the same visibility. The more their visibilities differ, the lower the ceiling on their PathSim score, regardless of how many paths connect them.

The Balance of Visibility property is what distinguishes PathSim from path count and random walk measures. A very prolific author cannot score a high PathSim with a junior researcher, even if they co-authored a paper, because their self-path counts — $M_{ii}$ and $M_{jj}$ — are very different. The formula automatically penalizes pairs with unequal visibility.

5. The Commuting Matrix

Computing PathSim efficiently requires a matrix formulation. For a meta path $\mathcal{P} = (A_1 \xrightarrow{R_1} A_2 \cdots A_{l+1})$, define the commuting matrix $M = W_{A_1 A_2} W_{A_2 A_3} \cdots W_{A_l A_{l+1}}$, where $W_{A_i A_j}$ is the adjacency matrix between objects of type $A_i$ and type $A_j$. The entry $M(i, j)$ counts the number of path instances between object $x_i$ of type $A_1$ and object $y_j$ of type $A_{l+1}$ under meta path $\mathcal{P}$.

For a symmetric meta path $\mathcal{P} = \mathcal{P}_l \mathcal{P}_l^{-1}$, the commuting matrix factors as $M = M_{\mathcal{P}_l} M_{\mathcal{P}_l}^T$ (since the commuting matrix for the reverse path is the transpose). Given this, PathSim can be written as: $$s(x_i, x_j) = \frac{2M(i,j)}{M_{ii} + M_{jj}}$$ where $M_{ii}$ is the diagonal entry (path count from $x_i$ back to itself).

The key challenge is that for long meta paths, the full commuting matrix $M$ is huge and dense. For the ACA (author–conference–author) path in DBLP, $M$ would be a $710K \times 710K$ matrix with up to $5G$ non-zero entries. Materializing this is impractical. The paper's solution is to partially materialize a shorter intermediate matrix $M_{\mathcal{P}_l}$ and concatenate online at query time.

6. Efficient Top-K Search

Two algorithms are proposed for computing top-k PathSim results efficiently.

PathSim-baseline pre-stores the commuting matrix for the partial meta path $\mathcal{P}_l^{-1}$ (the second half of the symmetric meta path) and computes the full matrix row for the query object online by vector-matrix multiplication. To avoid a full comparison with all $n$ candidates, it first identifies a candidate set by following the neighbor links of $x_i$ in the partial commuting matrix and taking their neighbors. This is much faster than pairwise comparison.

PathSim-pruning uses a co-clustering approach to generate upper bounds on PathSim scores and prune candidates that cannot make the top-k list. The objects of each type are grouped into clusters using a greedy KL-divergence-based co-clustering algorithm. For a query object, the algorithm first sorts target clusters (clusters of candidate objects) by an upper bound on their similarity to the query cluster. If the upper bound for an entire target cluster falls below the current k-th highest similarity score, the whole cluster can be pruned without computing individual similarities. This significantly reduces computation, especially for dense networks where the candidate set from the baseline algorithm is large.

Pause: connecting PathSim to familiar ideas

PathSim at path length 2 (a single intermediate type) is equivalent to Dice's similarity coefficient applied to the neighborhood sets of the two objects under that relation. For APA (author–paper–author), each author's "neighborhood" is their set of papers, weighted by paper co-authorship. PathSim measures the overlap normalized by the sizes of both neighborhoods. This is exactly Dice's coefficient from the ecology literature, where it was used to compare species distributions across habitats. PathSim generalizes Dice to arbitrary-length meta paths through the matrix multiplication formulation.

7. Experiments

The paper evaluates PathSim on the DBLP bibliographic network (710K+ authors, 1.2M papers, 5K venues) and on a Flickr photo network. Experiments compare PathSim against P-PageRank, SimRank, Random Walk (RW), and Pairwise Random Walk (PRW).

A key case study searches for the top-5 authors similar to "AnHai Doan" in the database and information systems (DBIS) area using the meta path APCPA (authors connected through the conferences they publish in). P-PageRank returns the most prominent (highly-ranked) authors in the area — big names — rather than peers of Doan. SimRank returns concentrated authors (those publishing at a small set of venues). PathSim returns Patel, Deshpande, Yang, and Miller — rising researchers in the database field who share very similar publication records with Doan. Human judges confirm that PathSim's results best capture the notion of "peer similarity."

Quantitative evaluation using labeled data (top-15 query results for 15 venue types in the DBIS dataset, evaluated by human annotators using a 0–2 relevance scale) and nDCG (Normalized Discounted Cumulative Gain, where higher is better) shows PathSim achieving an nDCG of 0.7446 compared to 0.5532 for P-PageRank, 0.6289 for SimRank, 0.7061 for RW, and 0.5284 for PRW. PathSim wins by a significant margin.

Clustering experiments on a "4-area dataset" (4 research areas, 20 venues, 1713 authors) using NMI (Normalized Mutual Information) confirm that PathSim similarity matrices produce better-quality clusters than any competing measure, for both venue type (NMI 0.8116) and author type (NMI 0.6501).

8. Lasting Impact

PathSim established the meta path as a first-class concept in heterogeneous information network analysis. Before this paper, most graph similarity work either ignored link types altogether (treating everything as a homogeneous network) or handled heterogeneity in ad-hoc, application-specific ways.

The paper launched a substantial research program. Subsequent work asked: what if the user does not know which meta path to use? This led to research on meta-path learning from examples. What if multiple meta paths should be combined? The paper already discusses linear combination of PathSim scores across multiple paths with user-specified weights. This was generalized by later work on graph neural networks over heterogeneous graphs, where meta paths serve as the structural skeleton for attention mechanisms (e.g., the HAN and HeCo models). Many recommendation systems, knowledge graph embedding models, and drug-discovery networks use meta-path-based similarity as a building block today.

The meta-path framework also influenced how heterogeneous graphs are used as benchmarks in the graph machine learning community (e.g., the DBLP and ACM datasets that appear in hundreds of graph neural network papers owe their organization to the taxonomic structure established by this line of work). PathSim's clean mathematical definition, the intuitive balance-of-visibility property, and the efficient algorithmic framework made it a lasting reference point.
